# Food Chain 3D Lab

An interactive 3D learning app about food chains. Students order an ocean food chain, identify producers and consumers, observe energy flow, and answer five questions about a grassland food chain.

- English is the default language. Use the language menu to switch to Traditional Chinese.
- The 3D scene can be rotated by dragging.
- Progress stays in place when the language changes during a session.
- The app works on desktop and mobile browsers.

## Run locally

Serve this folder with any static HTTP server, then open `index.html`. For example:

```sh
python3 -m http.server 8000
```
